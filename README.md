# SchoolProject - DevOps Practice Project

مشروع ASP.NET Core MVC بسيط (Student + Department) مجهز بالكامل بـ:
- Docker (Dockerfile متعدد المراحل)
- CI (GitHub Actions: restore, build, docker build, push to GHCR)
- CD (Self-hosted runner: pull + deploy تلقائي)
- docker-compose (تطوير محلي + نشر)

راجع تعليمات الإعداد الكاملة في المحادثة مع Claude.
